<p>
  Конструктор логики позволяет в едином образе формировать бизнес логику приложения.
  Потом ее можно экспортировать в один из языков программирования.
</p>
<p>
  На данный момент реализован экспорт в следующие языки: C#, C++, Rust, Go, TypeScript.
  Выберите <b>Проект → Настройка экспорта…</b> и добавьте цель: язык и папку (относительно папки проекта), куда
  попадёт его код. Целей может быть несколько, у каждой своя папка. Настройки сохраняются в проекте
  (<code>falang/config/logic-export.json</code>).
  <b>Проект → Экспортировать код</b> (Ctrl+Shift+E) генерирует код для всех целей, с индикатором прогресса и кнопкой
  отмены; ошибка в одной цели не останавливает остальные. Для C++, Go и C# получается один файл исходного кода, для
  TypeScript и Rust — по файлу на схему.
</p>
<p>
  Редактор предлагает только то, что умеют компилировать все целевые языки: в выражениях доступен сокращённый набор
  встроенных функций (основные функции <code>Math</code>, длина и индексация массивов и строк), поэтому код, который
  не удалось бы экспортировать, подсвечивается как ошибка уже при наборе.
</p>

#### Числовые типы

<p>
  У числовой переменной, параметра, возвращаемого значения или поля структуры всегда есть вид — без него целевые
  языки не могут объявить переменную. Вместо простого <code>number</code> в списке типов есть <b>integer</b>,
  <b>float</b> и <b>decimal</b>:
</p>
<ul>
  <li>
    <b>integer</b> — знаковые <code>int8</code>, <code>int16</code>, <code>int32</code> (по умолчанию),
    <code>int64</code> или беззнаковые <code>uint8</code>, <code>uint16</code>, <code>uint32</code>,
    <code>uint64</code>. Деление двух целых отбрасывает дробную часть (<code>7 / 2</code> даёт <code>3</code>,
    <code>-7 / 2</code> — <code>-3</code>) во всех языках, включая TypeScript; запись дробного значения в целую
    переменную тоже её отбрасывает. Переполнение ведёт себя так, как принято в целевом языке; в TypeScript значения не
    «заворачиваются».
  </li>
  <li><b>float</b> — <code>float32</code> или <code>float64</code> (по умолчанию).</li>
  <li>
    <b>decimal</b> — точное число с фиксированной точкой для денег и похожих величин: всего <i>digits</i> цифр (до 18),
    из них <i>decimals</i> после точки. <code>0.1 + 0.2</code> — ровно <code>0.3</code>; результаты умножения и
    деления, а также значения, записанные в переменную с меньшим числом знаков после точки, округляются по правилу
    «половина — от нуля»; при печати выводятся все знаки после точки (<code>12.50</code>). Decimal вместе с целым даёт
    decimal, вместе с float — float. В TypeScript decimal — обычный <code>number</code> (точно до 15 значащих цифр).
  </li>
</ul>
<p>
  При смешении двух ширин результат получает бо́льшую; при одинаковой ширине побеждает беззнаковая, целое вместе с
  float даёт float. В редакторе выражений любой вид — просто <code>number</code>. В схеме, сохранённой до появления
  видов чисел, <code>number</code> подсвечивается ошибкой на иконке, пока вы не выберете вид — автоматически ничего
  не меняется. Тип <code>any</code> и перечисления не предлагаются: их пока не компилирует ни один целевой язык.
</p>

<p>На данный момент существует четыре типа схем:</p>
<ul>
  <li>
    <b>Функция</b>. Может принимать на входе параметры, вызывать другие функции.
  </li>
  <li>
    <b>Структура объектов</b>: описание структур данных. Их можно использовать как типы данных в функции.
  </li>
  <li>
    <b>Перечисление</b>: именованный список значений. Экспорт перечислений пока не поддерживается.
  </li>
  <li>
    <b>Внешнее API</b>. Описание внешнего API. В коде, в зависимости от языка генерируются объекты либо интерфейсы.
    При вызове любой функции клиентский код обязан передать в качестве параметра реализацию данного API.
     В схеме функции есть возможность вызова АПИ добавлением соответствующей иконы.
  </li>
</ul>
