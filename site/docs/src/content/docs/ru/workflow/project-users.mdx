<p>
  Проект принадлежит пользователю, который его создал, — его <b>автору</b>. Других пользователей той же установки можно
  добавить в проект через <b>Проект → Пользователи</b> в тулбаре редактора: введите логин или e-mail, отметьте одну или
  обе роли и нажмите <b>Добавить</b>.
</p>

#### Роли

<ul>
  <li>
    <b>Редактор</b> — может всё, что и автор: редактировать схемы и интеграции, собирать, запускать, отлаживать,
    публиковать, пользоваться ИИ-агентом, менять настройки проекта и управлять его пользователями. Исключение одно:
    удалить проект может только автор.
  </li>
  <li>
    <b>Исполнитель</b> — не может открыть или изменить проект. В списке проектов он отмечен тегом «Исполнитель», а при
    открытии показываются только <a href="../human-tasks/">задачи</a> проекта: исполнитель их видит и выполняет.
  </li>
</ul>

<p>
  У одного пользователя могут быть обе роли. Роли меняются флажками в списке пользователей, кнопка <b>Удалить</b>
  убирает пользователя из проекта. Автор всегда стоит в списке первым и не меняется.
</p>

#### Назначение задач

<p>
  Когда сценарий создаёт задачу для человека, она назначается одному из исполнителей проекта — тому, у кого меньше всего
  открытых задач в этом проекте. Если исполнителей нет, задача достаётся автору. Когда пользователь теряет роль
  исполнителя, его открытые задачи так же раздаются оставшимся исполнителям (или автору). Назначение определяет только
  то, в чьей очереди задача: автор, все редакторы и все исполнители проекта по-прежнему видят все его задачи и могут
  выполнить любую. На странице задач есть колонка исполнителя и переключатель <b>Только мои</b>.
</p>

#### Кто платит

<p>
  Лимиты, квоты и серверы проекта считаются по аккаунту автора. Запросы к ИИ-агенту считаются по пользователю, который
  их отправил.
</p>

#### Администраторы

<p>
  Администратор платформы может управлять пользователями любого проекта: через <b>Проект → Пользователи</b> при
  просмотре проекта, или кнопкой <b>Пользователи</b> рядом с проектом в карточке пользователя («Подробнее») в админке. Там же кнопка <b>Передать</b> меняет владельца проекта — это
  может только администратор.
</p>
