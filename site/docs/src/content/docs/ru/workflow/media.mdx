<p>
  Интеграция <b>Медиа</b> обрабатывает изображения, видео и аудио через <a href="https://ffmpeg.org/">ffmpeg</a> —
  изменяет размер фото, делает превью, обрезает или склеивает ролики, конвертирует голосовое сообщение перед
  распознаванием. Каждое действие принимает и возвращает ссылку <a href="./files/">File</a>, никогда не сырые байты: вся
  работа выполняется на отдельном, выделенном сервисе, а не внутри процесса самого сценария. Учётные данные не нужны —
  интеграция доступна любому сценарию с момента создания проекта.
</p>

#### Действия

<ul>
  <li>
    <b>Проверить (probe).</b> Читает длительность, ширину/высоту, видео- и аудиокодек, битрейт и MIME-тип файла, ничего
    не меняя — обычный первый шаг перед тем, как решить, что делать с файлом неизвестной формы (например, с фото
    неизвестного размера, присланным пользователем).
  </li>
  <li>
    <b>Изменить размер изображения.</b> Вписывает изображение в заданную ширину/высоту (или обрезает, чтобы заполнить её
    целиком), с целевым форматом (исходный, JPEG, PNG или WebP) и качеством.
  </li>
  <li>
    <b>Конвертировать изображение.</b> Меняет формат и качество изображения без изменения размера.
  </li>
  <li>
    <b>Обрезать видео.</b> Вырезает фрагмент, начиная с заданного момента, заданной длительности — по умолчанию быстрым
    копированием потока (без перекодирования), либо с полным перекодированием, если срез должен точно попасть не на
    ключевой кадр.
  </li>
  <li>
    <b>Склеить видео.</b> Объединяет несколько роликов в один по порядку — быстрым копированием, если у всех входов уже
    совпадают кодек и разрешение, либо с перекодированием, если нет.
  </li>
  <li>
    <b>Превью видео.</b> Захватывает один кадр в заданный момент как изображение JPEG, с необязательной целевой шириной.
  </li>
  <li>
    <b>Транскодировать видео.</b> Перекодирует видео в один из нескольких фиксированных пресетов (720p/1080p для веба,
    пресет под размер Telegram, либо анимированный GIF) и целевой формат контейнера.
  </li>
  <li>
    <b>Извлечь аудио.</b> Достаёт аудиодорожку из видеофайла в формате MP3, AAC, WAV или Ogg.
  </li>
  <li>
    <b>Конвертировать аудио.</b> Меняет формат, битрейт, число каналов (моно/стерео) и частоту дискретизации аудиофайла
    — обычный шаг перед <b>«Вызвать AI (распознавание)»</b>, поскольку голосовое сообщение Telegram приходит в Ogg/Opus,
    а некоторые бэкенды распознавания ожидают другой формат.
  </li>
</ul>

#### Типичные цепочки

<ul>
  <li>
    <b>Голосовое сообщение Telegram → текст.</b> <code>message.voice</code> уже является <code>File</code> — примените к
    нему <b>«Конвертировать аудио»</b> (в MP3 или WAV), затем передайте результат в<b>«Вызвать AI (распознавание)»</b>.
  </li>
  <li>
    <b>Входящее фото → уменьшенная копия в ответ.</b> <b>«Проверьте»</b> входящее <code>message.photo</code>, чтобы
    узнать размер, <b>«Измените размер изображения»</b> (например, вписав в 800×800 в формате WebP), затем
    <b>«Отправьте файл»</b> обратно в чат.
  </li>
  <li>
    <b>Загрузка видео → превью.</b> <b>«Проверьте»</b> длительность, сделайте <b>«Превью видео»</b> на фиксированной
    отметке времени (или доле длительности) для картинки-превью и <b>«Транскодируйте видео»</b> в веб-пресет перед
    публикацией.
  </li>
</ul>

#### Ограничения и таймауты

<p>
  Каждое действие — это долгий шаг с отправкой heartbeat, а не быстрый вызов: транскодирование или крупная склейка могут
  занимать минуты, и платформа сообщает прогресс и позволяет отменить операцию во время выполнения (например, если сам
  сценарий остановлен), а не блокируется без обратной связи. Входные файлы проверяются по реальному контейнеру/кодеку до
  начала обработки, поэтому неподдерживаемый или повреждённый файл отклоняется рано, а не передаётся декодеру. Доступен
  только фиксированный набор операций — свободного доступа к произвольным опциям командной строки ffmpeg нет.
</p>
