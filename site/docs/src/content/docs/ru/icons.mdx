#### Основные понятия
<p>Базовая терминология перекочевала в Falang из визуального языка <a href='https://drakon.su/' target='_blank'>Дракон</a></p>
<ImageRow>
  <ol>
    <li><b>Шампур</b>: вертикальная линия, на которую "насаживаются" иконы.</li>
    <li><b>Икона "действие"</b>: атомарная часть схемы, задающая определенное действие.</li>
    <li><b>Макро-иконы</b>: составные иконы, которые внутри себя могут содержать ответвления, дочерние иконы и шампуры.</li>
    <li><b>Валентная точка</b>: место в алгоритме, куда могут быть вставлены другие иконы.</li>
  </ol>
  <img slot="media" src='/img/docs/basics.png' />
</ImageRow>

#### Простые иконы
<ImageRow>
  <ol>
    <li><b>Действие</b></li>
    <li><b>Ссылка</b>: если действие ссылается на другую схему, в углу появляется значек ссылки, нажав на который можно перейти к соответствующей схеме.</li>
    <li><b>Вывод</b>: вывод данных.</li>
    <li><b>Ввод</b>: применяется для ввода данных.</li>
    <li><b>Полка</b>: аналог иконы "действие", с двумя полями для ввода текста.</li>
  </ol>
  <img slot="media" src='/img/docs/simple-icons.png' />
</ImageRow>

#### Функция
<ImageRow>
  Функция - макро-икона, которая является единственной и главной на схеме соответствующего типа.
  В ее состав входит три блока:
  <ul>
    <li><b>Заголовок</b>, или комментарий: может использоваться для расширенного описания</li>
    <li><b>Название</b></li>
    <li><b>Завершающий блок</b></li>
  </ul>
  <img slot="media" src='/img/docs/icon-function.png' />
</ImageRow>

#### Жизнеритм
<ImageRow>
  Функция - макро-икона, которая является единственной и главной на схеме соответствующего типа.
  Аналог иконы "Силуэт" в Драконе. Позволяет удобно описывать продолжительные жизненные алгоритмы.
  <img slot="media" src='/img/docs/icon-liferythm.png' />
</ImageRow>

#### Дерево
<ImageRow>
  Функция - макро-икона, которая является единственной и главной на схеме соответствующего типа.
  Позволяет описывать древовидные структуры данных.
  <img slot="media" src='/img/docs/icon-tree.png' />
</ImageRow>

#### "Если"
<ImageRow>
  Макро-икона условного оператора, которая направляет действие алгоритма в зависимости от выполнения условия, описанного в основном блоке.
  Аналог "if - else" в программировании.
  <img slot="media" src='/img/docs/icon-if.png' />
</ImageRow>

#### Переключатель
<ImageRow>
  Макро-икона переключателя, которая направляет действие алгоритма на определенный дочерний шампур, если значение в основном блоке совпадает со значением в блоке варианта.
  Аналог "Switch" в программировании.
  <img slot="media" src='/img/docs/icon-switch.png' />
</ImageRow>

#### Параллельное исполнение
<ImageRow>
  Макро-икона, которая выполняет дочерние шампуры в параллельно. Действие идет дальше только после завршения всех параллельных процессов.
  <img slot="media" src='/img/docs/icon-parallel.png' />
</ImageRow>

#### Цикл для каждого
<ImageRow>
  Макро икона, проходящая по массиву данных, либо для переменной от минимального значение для максимального. Аналог for each.
  <img slot="media" src='/img/docs/icon-foreach.png' />
</ImageRow>

#### Цикл с условием
<ImageRow>
  Макро икона, которая повторяет выполнение процесса, пока выполняется некоторое-условие. Аналог while.
  <img slot="media" src='/img/docs/icon-while.png' />
</ImageRow>

#### Псевдо цикл
<ImageRow>
  Цикл, по факту выполняющийся один раз. Используется для применения в нем икон выхода либо продолжения (continue, break).
  <img slot="media" src='/img/docs/icon-pseudocycle.png' />
</ImageRow>

#### "Выходы"
<p>
  "Выходы" - обобщенное название группы икон, которы меняют прямой ход алгоритма.
</p>
<ol>
  <li><b>Выход</b> - выход из цикла (аналог break в программировании)</li>
  <li><b>Продолжить</b> - продолжить цикл сначала (аналог continue)</li>
  <li><b>Возврат</b> - возврат из функции (аналог return)</li>
  <li><b>Ошибка</b> - прерывание алгоритма в результате ошибки (аналог throw)</li>
</ol>
<Gallery>
  <img src='/img/docs/outs-types.png' />
</Gallery>
<p>В случае вложенных циклов, иконы "Выход" и "Продолжить" в конце имеют индексы 1,2,... Индекс означает уровень внешнего цикла, к которому выход применяется.</p>

#### Таймер
<p>
  Таймер — боковая иконка, присоединённая слева к другой иконе. Он обозначает паузу или ожидание (аннотация «таймер» в ДРАКОН) и хранит собственный текст, например длительность задержки. Таймер — это дополнение к иконе, а не отдельный шаг: на порядок выполнения он не влияет.
</p>
<p>
  В текстовых проектах таймер можно прикрепить к иконам <b>Действие</b>, <b>Ссылка</b>, <b>"Если"</b>, <b>Переключатель</b>, <b>Цикл для каждого</b> и <b>Цикл с условием</b>. Щёлкните по иконе правой кнопкой мыши и выберите «Таймер». Двойной щелчок по таймеру открывает редактирование текста, потянув за край, можно изменить размер, а правый щелчок по таймеру и пункт «Удалить» убирают его. У одной иконы может быть только один таймер.
</p>
