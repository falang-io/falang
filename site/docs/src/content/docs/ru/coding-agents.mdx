<p>
  Агент для программирования, например{' '}
  <a href="https://claude.com/claude-code" target="_blank">
    Claude Code
  </a>
  , или любой другой клиент протокола Model Context Protocol (MCP) может работать с проектами Falang напрямую: читать
  схемы, создавать и менять их, а в Workflow-конструкторе — ещё и собирать, запускать, отлаживать и публиковать. Это
  альтернатива встроенному <a href="../ai-agent/">ИИ-агенту</a>, которая работает по вашей собственной подписке и в
  вашем терминале. Каждое изменение агента проверяется так же, как в редакторе; некорректная схема отклоняется с
  указанием места ошибки, и ничего не сохраняется.
</p>

#### Десктопные проекты

<p>
  При создании или открытии проекта десктопное приложение кладёт в его папку два файла, если их там ещё нет:{' '}
  <code>.mcp.json</code>, который подключает собственный MCP-сервер проекта <b>falang</b>, и <code>CLAUDE.md</code> —
  короткое описание проекта для агента. Существующие файлы никогда не перезаписываются.
</p>
<ol>
  <li>
    Откройте терминал в папке проекта (или в любой папке внутри неё) и запустите агента, например <code>claude</code>.
  </li>
  <li>Разрешите MCP-сервер проекта, когда агент спросит об этом в первый раз.</li>
  <li>Опишите, что нужно построить или изменить.</li>
</ol>
<p>
  Сервер — небольшая программа на Node.js, которая поставляется с приложением, поэтому{' '}
  <b>нужен установленный Node.js</b>, доступный как <code>node</code>. У каждой папки проекта свой сервер; само
  приложение при этом может быть не запущено.
</p>
<p>Агент получает такие инструменты:</p>
<ul>
  <li>
    <code>get_project</code>, <code>list_documents</code>, <code>get_document</code> — чтение проекта, его дерева и
    схемы;
  </li>
  <li>
    <code>get_node_kinds</code> — какие иконки может содержать схема, их поля и что куда можно вставлять;
  </li>
  <li>
    <code>set_document</code> — замена схемы новой, проверенной версией (расположение оставшихся иконок сохраняется);
  </li>
  <li>
    <code>create_document</code>, <code>rename_document</code>, <code>move_document</code>, <code>delete_document</code>
    , <code>create_folder</code> — работа с документами и папками;
  </li>
  <li>
    <code>lock_document</code>, <code>unlock_document</code> — блокировка правки, о которой ниже.
  </li>
</ul>
<p>
  Имена функций подчиняются тому же правилу, что и в редакторе: латиница в camelCase, например{' '}
  <code>myFunctionName</code>. В проекте Arduino агент может править <code>setup</code>, <code>loop</code> и другие
  схемы, включая иконки выводов и драйверов, но не может переименовывать, перемещать и удалять закреплённые документы,
  читать и заменять таблицы <code>Devices</code> (<code>get_devices</code>/<code>set_devices</code>), но не может
  компилировать или загружать скетч — для этого используйте <b>Build &amp; Upload</b> в приложении. Агент также может
  писать, проверять и сохранять новые драйверы устройств (см.{' '}
  <a href="../arduino/drivers/">Собственные драйверы устройств</a>).
</p>

#### Пока агент правит

<ul>
  <li>
    Схема, которую меняет агент, <b>заблокирована</b>: если она открыта в приложении, её вкладка закрыта надписью
    «Locked by an agent until …», а ваши правки в ней не сохраняются, пока блокировка не снята. Блокировка действует
    пять минут после последнего обращения агента или заканчивается сразу, когда агент её снимает.
  </li>
  <li>
    Открытое приложение само подхватывает изменения агента: схема без несохранённых правок перезагружается на месте, а
    дерево проекта отражает новые, переименованные и удалённые документы.
  </li>
  <li>
    Если схема изменилась на диске, пока в ней есть ваши несохранённые правки, приложение спросит:{' '}
    <b>Reload (discard my changes)</b> (перезагрузить, отбросив правки) или <b>Keep mine</b> (оставить свои — тогда
    следующее сохранение перезапишет файл).
  </li>
</ul>

#### Workflow-конструктор

<p>
  Backend Workflow-конструктора отдаёт MCP по HTTP по адресу <code>/mcp</code> на своём хосте — например,{' '}
  <code>https://api.workflow.falang.ru/mcp</code> или <code>http://localhost:4100/mcp</code> для{' '}
  <a href="../workflow/local-setup/">локального стенда</a>. Доступ — по персональному токену.
</p>
<ol>
  <li>
    В веб-приложении нажмите <b>«Токены доступа»</b> в шапке списка проектов, затем <b>«+ Новый токен»</b>. Дайте ему
    название (например, «Claude Code на ноутбуке»); при желании ограничьте его одним <b>проектом</b> и задайте срок
    действия в днях. Сразу скопируйте токен — он начинается с <code>flg_pat_</code> и показывается только один раз.
    Отозвать токен можно в том же окне в любой момент; всё, что его использует, сразу перестаёт работать.
  </li>
  <li>
    Подключите сервер к агенту, для Claude Code:
    <pre>
      <code>{`claude mcp add --transport http falang-workflow https://api.workflow.falang.ru/mcp \\
  --header "Authorization: Bearer flg_pat_…"`}</code>
    </pre>
  </li>
</ol>
<p>
  Агент получает те же инструменты для документов, что и в десктопе (с идентификатором проекта), и ещё инструменты,
  чтобы:
</p>
<ul>
  <li>просматривать, создавать, импортировать и экспортировать проекты (экспорт никогда не содержит секретов);</li>
  <li>искать интеграции по ключевым словам и смотреть учётные данные проекта (только названия, без секретов);</li>
  <li>
    смотреть скомпилированный код, собирать и запускать функцию на тестовом стенде, следить за ходом и историей запуска;
  </li>
  <li>отлаживать на тестовом стенде: точки останова, пауза, продолжение, шаг с обходом;</li>
  <li>публиковать версию, смотреть список версий, активировать прежнюю или останавливать версию.</li>
</ul>
<p>
  Токен, ограниченный одним проектом, не видит других проектов и не может создавать новые. Блокировки работают так же,
  как в десктопе: документ, который меняет агент, в браузере закрыт надписью «Заблокировано агентом до …», а ваша
  правка, сделанная в это время, помечается как несохранённая.
</p>

#### Плагин для Claude Code

<p>
  Папка <code>plugins/falang</code> в{' '}
  <a href="https://github.com/falang-io/falang" target="_blank">
    репозитории Falang
  </a>{' '}
  — это плагин для Claude Code с тремя навыками, которые объясняют агенту модель схем, иконки и драйверы Arduino и цикл
  сборки, запуска и публикации Workflow, плюс готовое подключение MCP-сервера Workflow-конструктора. Он не обязателен —
  десктопные проекты работают и без него, — но заметно повышает точность работы агента. Из клона репозитория:
</p>
<pre>
  <code>{`claude plugin marketplace add ./plugins
claude plugin install falang@falang`}</code>
</pre>
<p>
  С установленным плагином сервер Workflow-конструктора настраивается двумя переменными окружения вместо{' '}
  <code>claude mcp add</code>:
</p>
<pre>
  <code>{`export FALANG_MCP_URL="https://api.workflow.falang.ru/mcp"
export FALANG_TOKEN="flg_pat_…"`}</code>
</pre>
