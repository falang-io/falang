<p>
  Falang для Arduino — десктопное приложение для программирования плат Arduino блок-схемами. Вы рисуете{' '}
  <code>setup</code> и <code>loop</code> схемами, описываете подключение в документе <code>Devices</code>, а приложение
  собирает всё в обычный скетч Arduino, загружает его на плату и позволяет отлаживать прямо на железе.
</p>

#### Что нужно установить

<ul>
  <li>
    <a href="https://arduino.github.io/arduino-cli/" target="_blank">
      arduino-cli
    </a>
    — через него приложение компилирует и загружает скетч; в комплект он не входит. Приложение ищет его в{' '}
    <code>PATH</code>, в обычных местах установки (Homebrew на macOS, <code>Program Files\Arduino CLI</code> на Windows,{' '}
    <code>~/.local/bin</code> на Linux) и внутри установленной Arduino IDE 2, в которую он встроен. Чтобы указать копию
    в другом месте, запустите приложение с переменной окружения <code>FALANG_ARDUINO_CLI</code>, равной полному пути к
    нему. Если найти его не удалось, об этом скажет диалог <b>«Сборка и загрузка»</b>.
  </li>
  <li>
    Ядро для вашей платы, один раз через arduino-cli: <code>arduino-cli core install arduino:avr</code> для Uno, Nano и
    Mega, <code>esp32:esp32</code> для ESP32.
  </li>
  <li>
    Только для драйвера RGB-ленты: <code>arduino-cli lib install "Adafruit NeoPixel"</code>. Остальным встроенным
    драйверам дополнительные библиотеки не нужны.
  </li>
</ul>

#### Проекты

<p>
  <b>Файл → Новый проект…</b> спрашивает название, папку и плату — Arduino Uno, Nano, Nano (old bootloader), Mega 2560
  или ESP32 Dev Module. В каждом проекте три закреплённых документа: <code>setup</code>, <code>loop</code> и{' '}
  <code>Devices</code>; любая другая добавленная схема — вспомогательная функция, которую можно вызывать из них.
  Привязка платы и документ <code>Devices</code> описаны в разделе <a href="./project-setup/">Настройка проекта</a>.
</p>

#### Иконки

<p>
  В схеме есть обычные иконки и специальные для Arduino — они собраны в группах <b>«Arduino»</b> (пины и встроенные
  функции) и <b>«Устройство»</b> (действия устройств, добавленных в <code>Devices</code>) меню вставки.
</p>
<ul>
  <li>
    <b>Обычные иконки</b> — новая переменная, действие, вызов функции, «если», переключатель, циклы (для каждого, от/до,
    пока, цикл) и выходы (прервать, продолжить, возврат). Выражения пишутся в синтаксисе, похожем на TypeScript, но
    ограниченном тем, что переводится в C++; доступны функции и константы Arduino: <code>digitalRead</code>,{' '}
    <code>analogWrite</code>, <code>millis</code>, <code>map</code>, <code>constrain</code>, <code>HIGH</code>/
    <code>LOW</code>, <code>A0</code>…<code>A7</code> и другие.
  </li>
  <li>
    <b>Пины</b>: <b>Set digital pin</b> (номер пина и переключатель HIGH/LOW), <b>Set analog pin (PWM)</b> (ползунок
    0–255), <b>Read digital pin</b> и <b>Read analog pin</b> (каждая сохраняет прочитанное значение в новую переменную;
    для аналогового чтения пин — это номер канала, 0 для A0). Режимы пинов задаются в документе <code>Devices</code>, а
    не иконкой.
  </li>
  <li>
    <b>Встроенные функции</b>: <b>Delay</b>, <b>Delay (microseconds)</b>, <b>Millis</b>, <b>Micros</b>, <b>Random</b>,{' '}
    <b>Random seed</b>, <b>Serial begin</b>, <b>Serial print</b>, <b>Serial println</b>. Их аргументы — фиксированные
    числа; чтобы вывести переменную, напишите <code>Serial.println(x)</code> в действии.
  </li>
  <li>
    <b>Действия драйверов</b> — по иконке на каждое действие каждого установленного драйвера, с заголовком
    «&lt;драйвер&gt;: &lt;действие&gt;», например <b>Servo: Set angle</b>.
  </li>
</ul>
<p>
  Переменные могут быть целыми числами и числами с плавающей точкой разных размеров, а также логическими. Строки,
  массивы и структуры в проектах Arduino пока не поддерживаются, как и иконки <b>«Лог»</b> и <b>«Исключение»</b> — у
  платы нет консоли и исключений.
</p>

#### Встроенные драйверы

<ul>
  <li>
    <b>Servo</b> — <i>Set angle</i> (пин, 0–180°).
  </li>
  <li>
    <b>DHT11 / DHT22</b> — <i>Read temperature (°C)</i>, <i>Read humidity (%RH)</i>; при ошибке чтения результат — NaN.
    Между чтениями нужно 1–2 секунды.
  </li>
  <li>
    Ультразвуковой датчик <b>HC-SR04</b> — <i>Read distance (cm)</i>; −1 при таймауте.
  </li>
  <li>
    <b>LCD1602 (I2C)</b> и <b>LCD1602 (Parallel)</b> — <i>Clear display</i>, <i>Print text</i> (столбец, строка и текст;
    в текст можно вставлять выражения как <code>{'${…}'}</code>). Добавьте дисплей в документ <code>Devices</code>,
    чтобы он инициализировался при старте.
  </li>
  <li>
    <b>Адресная RGB-лента (WS2812/NeoPixel)</b> — <i>Set pixel color</i> и <i>Show</i> (отправить цвета на ленту). Нужна
    библиотека Adafruit NeoPixel.
  </li>
</ul>
<p>В скетч копируются только те драйверы, которые в нём действительно используются.</p>

#### Собственные драйверы

<p>
  Можно добавлять собственные драйверы устройств — для одного проекта или в личную библиотеку, общую для всех ваших
  проектов — и управлять ими через <b>Sketch → Drivers…</b>. Подробности в разделе{' '}
  <a href="./drivers/">Собственные драйверы устройств</a>.
</p>

#### Сборка и загрузка

<p>
  <b>Скетч → Сборка и загрузка…</b> открывает диалог (его подписи пока на английском) с платой проекта и списком{' '}
  <b>Port</b> (с кнопкой <b>Refresh</b>):
</p>
<ul>
  <li>
    <b>Compile</b> генерирует скетч и компилирует его без загрузки;
  </li>
  <li>
    <b>Upload</b> компилирует текущие схемы и загружает их на плату через выбранный порт;
  </li>
  <li>
    <b>Upload (debug)</b> загружает сборку с трассировкой и запускает <a href="./debugging/">отладчик</a>.
  </li>
</ul>
<p>
  Сгенерированный скетч лежит в папке проекта как <code>src/sketch/sketch.ino</code> вместе с используемыми драйверами;
  папка перезаписывается при каждой сборке. Ошибки в схемах перечисляются с именем документа, а при сбое arduino-cli в
  диалоге показывается его полный вывод.
</p>
