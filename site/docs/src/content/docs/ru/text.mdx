<p>Текстовые алгоритмы позволяют визуализировать алгоритмы на человеческом языке.</p>
<p>На данный момент в текстовых алгоритмах доступны три вида схем:</p>
<ul>
  <li><b>Функция</b>: алгоритм в виде функции</li>
  <li><b>Силуэт</b>: диаграмма длительных процессов. Аналог иконы "силуэт" в Драконе.</li>
  <li><b>Дерево</b>: для описание древовидных структур</li>
</ul>

#### Форматирование текста
<p>Двойной клик по текстовой иконке открывает редактор с панелью форматирования: полужирный, курсив, подчёркнутый, зачёркнутый текст, выравнивание по левому/центру/правому краю или по ширине, маркированные и нумерованные списки, отмена и повтор действия. Также можно вставлять изображения — потяните за маркеры на выделенном изображении, чтобы изменить его размер, и используйте кнопки выравнивания абзаца, чтобы расположить его по центру или по правому краю.</p>
