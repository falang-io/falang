<p>
  В проекте с кодом алгоритм рисуется схемой, в иконках которой записан обычный исходный код на одном языке. Falang
  этот код не проверяет и не переводит: он раскладывает управляющую логику (условия, циклы, выходы) и собирает текст
  иконок в файл исходного кода. Так можно спроектировать или задокументировать алгоритм наглядно и всё равно получить
  файл, который компилируется.
</p>

#### Языки

<p>
  Язык выбирается при создании проекта — <b>Код (C++)</b>, <b>Код (JavaScript)</b>, <b>Код (TypeScript)</b>,{' '}
  <b>Код (PHP)</b> или <b>Код (Rust)</b>. В одном проекте один язык. Схем в нём может быть сколько угодно, в том числе
  в папках; новый проект начинается с одной схемы <b>Main</b>.
</p>

#### Что вводится в иконки

<p>Каждое поле — это обычный исходный код на языке проекта, с подсветкой синтаксиса.</p>
<ul>
  <li>
    <b>Функция</b> — сама схема. Её верхний блок — заголовок функции, целиком (например, <code>int main()</code> или{' '}
    <code>fn main()</code>); нижний блок — завершающий код, который пишется последним (например,{' '}
    <code>return 0;</code>). Из имени схемы ничего не генерируется.
  </li>
  <li>
    <b>Действие</b> — один или несколько операторов; можно в несколько строк.
  </li>
  <li>
    <b>Если</b> и <b>Пока</b> — только условие, без ключевого слова и скобок: <code>x &gt; 0</code>. Пункт «Поменять
    true/false» в контекстном меню меняет, какая ветка считается «истинной».
  </li>
  <li>
    <b>Переключатель</b> — значение, по которому идёт выбор; в каждом варианте — его значение. Вариант со значением{' '}
    <code>default</code> становится веткой по умолчанию.
  </li>
  <li>
    <b>Для каждого</b> — весь заголовок цикла в синтаксисе языка, например <code>for (const x of items)</code>,{' '}
    <code>for x in items</code> или <code>foreach ($items as $x)</code>.
  </li>
  <li>
    <b>Цикл</b> — без поля: тело выполняется один раз, а <b>Продолжить</b> внутри него запускает его снова.
  </li>
  <li>
    <b>Прервать</b>, <b>Продолжить</b>, <b>Возврат</b> (с необязательным значением) и <b>Исключение</b> (со значением)
    — предлагаются в конце ветки или тела цикла, см. <a href="../basics/">Основы работы со схемами</a>.
  </li>
</ul>
<p>
  Код <b>не проверяется</b>: при наборе нет отметок об ошибках, и ошибка обнаружится только при компиляции
  сгенерированного файла.
</p>

#### Генерация файлов

<p>
  Выберите <b>Проект → Экспортировать документы кода</b>. Каждая схема проекта становится одним файлом в папке{' '}
  <code>generated</code> проекта и называется по схеме (<code>generated/Main.cpp</code>, <code>Main.rs</code>, …). Все
  файлы попадают в эту одну папку, в каких бы папках ни лежали схемы; символы, недопустимые в имени файла, заменяются
  на <code>_</code>, а к повторяющемуся имени добавляется короткий суффикс. Показывается окно с ходом выполнения и
  кнопкой <b>Отмена</b>; ошибка в одной схеме не останавливает остальные. Файлы создаются только этой командой, не при
  сохранении.
</p>
<p>Схема превращается в заголовок, затем блок с её иконками и завершающим кодом:</p>

```cpp
int main()
{
  if (x > 0) {
    printf("yes\n");
  } else {
    continue;
  }
  while (i < 10) {
    i++;
    break;
  }
  return 0;
}
```

#### Различия языков

<ul>
  <li>
    <b>C++, JavaScript, TypeScript и PHP</b> используют общую C-подобную форму выше. <b>Переключатель</b> становится{' '}
    <code>switch</code>, где каждый вариант — в своём блоке <code>{'{ }'}</code> и без автоматического{' '}
    <code>break;</code> — выход нужно поставить самому. <b>Цикл</b> становится{' '}
    <code>while (true) {'{ … break; }'}</code>. Блок <code>else</code> пишется всегда, даже если его ветка пуста.
  </li>
  <li>
    Файлы <b>PHP</b> обёрнуты в <code>&lt;?php … ?&gt;</code>.
  </li>
  <li>
    <b>Rust</b>: условия без скобок (<code>if x &gt; 0 {'{'}</code>), <b>Переключатель</b> становится{' '}
    <code>match</code>, а <code>default</code> пишется как <code>_</code>, <b>Цикл</b> становится{' '}
    <code>loop {'{ … break; }'}</code>, <b>Исключение</b> — <code>panic!(…)</code>.
  </li>
  <li>
    <b>Прервать</b> и <b>Продолжить</b> всегда относятся к ближайшему циклу; выходы из внешних циклов с номером в
    проектах с кодом недоступны.
  </li>
</ul>
