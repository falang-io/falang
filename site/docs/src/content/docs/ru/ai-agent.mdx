<p>
  В десктопных приложениях — Falang и Falang для Arduino — есть встроенный ИИ-агент: опишите обычными словами, что нужно
  изменить, и он правит схемы теми же действиями, что и вы вручную (вставка, перемещение и удаление иконок, изменение их
  текста). Каждое изменение сразу видно на холсте, и его можно отменить. У веб-конструктора Workflow свой агент, см.{' '}
  <a href="../workflow/ai-agent/">ИИ-агент</a> в разделе Workflow.
</p>

#### Настройка

<p>
  Агент работает с любым OpenAI-совместимым API: с самим OpenAI, с другим провайдером с совместимым API или с локальным
  сервером. Выберите <b>Настройки → Агент…</b> и заполните:
</p>
<ul>
  <li>
    <b>Base URL</b> — корневой адрес API, например <code>https://api.openai.com/v1</code>;
  </li>
  <li>
    <b>API key</b> — ваш ключ для этого API;
  </li>
  <li>
    <b>Model</b> — имя модели, например <code>gpt-4o-mini</code>.
  </li>
</ul>
<p>
  Настройки относятся к приложению на этом компьютере и действуют для всех проектов. Они хранятся в собственном файле
  настроек приложения, а не в папке проекта, поэтому ключ не попадёт в проект, которым вы делитесь или который
  коммитите. Пока агент не настроен, его панель показывает подсказку открыть <b>Настройки → Агент…</b>.
</p>

#### Как открыть агента

<p>
  Выберите <b>Проект → Агент</b> (в приложении для Arduino — <b>Скетч → Агент</b>). Чат открывается в правой боковой
  панели, которую он делит с историей версий, — одновременно показывается что-то одно. Чат относится ко всему проекту, а
  не к одной вкладке: переключение вкладок не прерывает выполняющийся запрос. Кнопка <b>«Остановить»</b> отменяет его.
</p>

#### Что агент умеет менять

<ul>
  <li>
    В Falang: функции проектов <a href="../logic/">конструктора логики</a> и схемы{' '}
    <a href="../code/">проектов с кодом</a>. Текстовые проекты не поддерживаются.
  </li>
  <li>
    В Falang для Arduino: <code>setup</code>, <code>loop</code> и остальные ваши схемы. В документе <code>Devices</code>{' '}
    агент может читать и заменять таблицы выводов и устройств.
  </li>
  <li>
    Агент не ограничен открытой вкладкой: он может читать и менять другие схемы проекта и сам открывает вкладку схемы, с
    которой начинает работать.
  </li>
  <li>
    Новые документы он не создаёт — создайте схему сами и попросите агента её заполнить или воспользуйтесь{' '}
    <a href="../coding-agents/">агентом для программирования</a>, который это умеет.
  </li>
</ul>

#### Отмена

<p>
  Один запрос — это один шаг отмены в каждой затронутой схеме. Кнопки <b>«Отменить»</b> и <b>«Повторить»</b> в панели
  (или Ctrl+Z в схеме) откатывают и возвращают весь запрос разом; ваши собственные правки, сделанные после него, —
  отдельные шаги.
</p>

#### Сессии чата

<p>
  Разговоры хранятся как сессии проекта: можно начать новую, переключаться между ними, переименовать, удалить или
  экспортировать сессию в JSON-файл. Сессии сохраняются в папке проекта, по файлу на сессию в{' '}
  <code>falang/agent-sessions/</code>. Под каждым ответом панель показывает, сколько токенов он потратил, а отдельные
  шаги агента можно раскрыть.
</p>

#### Уточняющие вопросы

<p>
  Если запрос неоднозначен так, что от этого зависит результат, агент останавливается и задаёт один вопрос с несколькими
  вариантами вместо того, чтобы гадать. Нажмите на вариант, выберите <b>«Другое…»</b>, чтобы ввести свой ответ, или{' '}
  <b>«Реши сам»</b>, чтобы агент выбрал сам; ответ продолжает тот же разговор. Подряд агент задаёт не больше трёх
  вопросов. Чтобы вопросов не было совсем, включите в панели <b>«Не спрашивать, просто делать»</b> — настройка
  запоминается для каждого проекта.
</p>
