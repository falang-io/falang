#### Falang - это универсальное решение для построения блок-схем

<p>
  Построен на базе веб технологий, что позволяет его использовать как в приложениях рабочего стола, так и внедрять в
  веб-приложения.
</p>
#### Установка
<p>Приложение доступно для Windows, Linux, MacOS. Для установки необходимо скачать дистрибутив и запустить его.</p>
<p>
  <b>
    <a href="https://download.falang.io/releases/stable/default" target="_blank">
      Ссылка для скачивания
    </a>
  </b>
  .
</p>
<p>
  После установки запустите программу и выберите <b>Файл → Новый проект…</b> (или нажмите <b>Новый проект…</b> на
  стартовой странице). В диалоге создания проекта укажите название, папку и тип проекта. Проект, созданный в прежней
  версии Falang, автоматически конвертируется при первом открытии; копия исходных файлов сохраняется в его папке{' '}
  <code>backup</code>.
</p>
#### Типы проектов
<p>В десктопном приложении Falang есть три вида проектов:</p>
<ul>
  <li>
    <a href="./text/">
      <b>Текстовые</b>
    </a>{' '}
    - позволяют визуализировать алгоритмы на человеческом языке.
  </li>
  <li>
    <a href="./logic/">
      <b>Конструктор логики</b>
    </a>{' '}
    - универсальный конструктор бизнес логики, с возможностью генерации кода в различные языки программирования: C++,
    Rust, Go, C#, TypeScript.
  </li>
  <li>
    <a href="./code/">
      <b>Код</b>
    </a>{' '}
    (C++, JavaScript, TypeScript, PHP или Rust — язык выбирается при создании проекта) - схемы алгоритмов, в
    иконках которых записан исходный код на этом языке, с подсветкой синтаксиса. Код не проверяется; пункт{' '}
    <b>Проект → Экспортировать документы кода</b> собирает по одному файлу исходного кода на схему в папку{' '}
    <code>generated</code> проекта.
  </li>
</ul>
<p>На том же движке схем построены ещё два продукта:</p>
<ul>
  <li>
    <a href="./arduino/">
      <b>Falang для Arduino</b>
    </a>{' '}
    - отдельное десктопное приложение: компилирует схемы в скетч Arduino, загружает его на плату и позволяет отлаживать
    прямо на железе.
  </li>
  <li>
    <a href="./workflow/">
      <b>Workflow-конструктор</b>
    </a>{' '}
    - веб-редактор автоматизаций и бизнес-процессов с надёжным (durable) исполнением сценариев на Temporal.
  </li>
</ul>
#### Возможности десктопного приложения
<ul>
  <li>
    <b>Файлы проекта.</b> Проект — это обычная папка: <code>falang.json</code> описывает проект, а каждая схема лежит
    отдельным JSON-файлом в <code>falang/schemes/</code> и называется так же, как схема; папки дерева проекта — настоящие
    папки на диске. Такой проект удобно хранить в git и читать другими инструментами.
  </li>
  <li>
    <b>История версий.</b> <b>Проект → История версий</b> (в приложении для Arduino — <b>Скетч → История версий</b>)
    показывает сохранённые версии, сравнивает любые две из них бок о бок и восстанавливает более старую. Версии хранятся
    в git-репозитории; репозиторий и автор настраиваются в <b>Настройки → Версионирование…</b>.
  </li>
  <li>
    <a href="./ai-agent/"><b>ИИ-агент.</b></a> <b>Проект → Агент</b> открывает чат, который правит схемы по описанию на обычном языке — так же, как{' '}
    <a href="./workflow/ai-agent/">агент Workflow-конструктора</a>. Нужен свой OpenAI-совместимый адрес, модель и
    API-ключ — они задаются один раз в <b>Настройки → Агент…</b>.
  </li>
  <li>
    <a href="./coding-agents/"><b>Агенты для программирования.</b></a> Приложение кладёт в папку каждого проекта файлы <code>.mcp.json</code> и{' '}
    <code>CLAUDE.md</code> (только если их там ещё нет). Агент с поддержкой MCP, например Claude Code, запущенный в этой
    папке, получает инструменты для чтения, правки и проверки схем. Пока он правит схему, её открытая вкладка
    блокируется и показывает об этом заставку.
  </li>
  <li>
    <a href="./pdf-export/">
      <b>Экспорт в PDF</b>
    </a>{' '}
    - печать схем, по одной странице на схему.
  </li>
  <li>
    <b>Язык интерфейса</b> - <b>Настройки → Язык…</b> (русский или английский).
  </li>
</ul>
