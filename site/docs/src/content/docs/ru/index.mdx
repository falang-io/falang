#### Falang - это универсальное решение для построения блок-схем

<p>
  Построен на базе веб технологий, что позволяет его использовать как в приложениях рабочего стола, так и внедрять в
  веб-приложения.
</p>
#### Установка
<p>Приложение доступно для Windows, Linux, MacOS. Для установки необходимо скачать дистрибутив и запустить его.</p>
<p>
  <b>
    <a href="https://download.falang.io/releases/stable/default" target="_blank">
      Ссылка для скачивания
    </a>
  </b>
  .
</p>
<p>
  После установки запустите программу, и нажмите Файл -&gt; Создать проект. В диалоге создания проекта укажите название,
  папку и тип проекта.
</p>
#### Типы проектов
<p>На данный момент есть 2 варианта построения диаграм:</p>
<ul>
  <li>
    <a href="./text/">
      <b>Текстовые</b>
    </a>{' '}
    - позволяют визуализировать алгоритмы на человеческом языке.
  </li>
  <li>
    <a href="./logic/">
      <b>Конструктор логики</b>
    </a>{' '}
    - универсальный конструктор бизнес логики, с возможностью генерации кода в различные языки программирования: C++,
    Rust, Go, C#, TypeScript (JavaScript).
  </li>
</ul>
<p>
  Отдельно развивается{' '}
  <a href="./workflow/">
    <b>Workflow-конструктор</b>
  </a>{' '}
  - визуальный редактор автоматизаций и бизнес-процессов с надёжным (durable) исполнением сценариев на Temporal.
</p>
