#### Directory tree
<ImageRow>
  On the left side of the application there is a directory tree. To create a folder or outline, right-click on an empty space.
  <img slot="media" src='/img/docs/directories-tree.png' />
</ImageRow>

#### Insert / delete
<ImageRow>
  <p>
    To insert an icon, right-click on the valence point and click on the menu item with the corresponding icon.
    To delete - right-click on the icon and select "delete".
  </p>
  <p>
    If you need to copy an icon to another location, select the "copy" item on the icon, and select "paste" at another valence point.
  </p>
  <p>
    Depending on the location of the valence point, the program can offer various options for insertion.
  </p>
  <video slot="media" loop autoplay muted playsinline>
    <source src="/img/docs/insert-delete.webm" type="video/webm" />
  </video>
</ImageRow>

#### Transfer
<ImageRow>
  <p>
    To transfer an icon, hold down the mouse button over it and drag it to the valence point to which you want to transfer this icon.
  </p>
  <p>
    To transfer a group of icons, first click on one icon, then, with the Shift key pressed, click on another icon located on the same skewer.
    Then transfer this group of icons to the desired valence point.
  </p>
  <video slot="media" loop autoplay muted playsinline>
    <source src="/img/docs/move.webm" type="video/webm" />
  </video>
</ImageRow>

#### Resizing
<ImageRow>
  <p>

#### "Outputs"
<ImageRow>
  <p>Exit icons (break, continue, return, throw) appear in the menu if the valence point satisfies the following conditions:</p>
  <ul>
    <li>The valence point is the last one in this skewer</li>
    <li>The skewer is not on the main axis of the algorithm or this macro icon</li>
  </ul>
